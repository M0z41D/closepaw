Your phone, on autopilot.

ClosePaw is an AI agent for Android that operates your phone for you. Tell it what you need in plain English — book a ride, catch up on emails, compare prices, summarize a thread — and watch it tap through the apps to get it done.


HOW IT WORKS

• Type a task in natural language ("Open Amazon, find the cheapest AirPods Pro")
• The agent reads your screen, plans the steps, and executes them
• Watch every tap and swipe through the Smart Capsule overlay
• Pause or take over at any time


FEATURES

• Natural-language task execution across any Android app
• Smart Capsule — a floating panel that works inside any app, so you never leave your current context
• Choose your AI provider: OpenAI, OpenRouter, or any compatible API
• Real-time action visualization — see exactly what the agent is doing
• Full control — pause, take over, or stop any task instantly
• Cross-session memory — the agent remembers what worked


PRIVACY BY DESIGN

• No root required
• No screen recording
• No tracking, no telemetry
• Your API key stays on device
• Screen content goes only to your chosen AI provider, and only during active tasks
• Open source under Apache 2.0


REQUIREMENTS

• Android 12 or later (API 31+)
• Accessibility service permission (so ClosePaw can read the screen and tap on your behalf)
• "Display over other apps" permission (for the Smart Capsule overlay)
• An API key from OpenAI, OpenRouter, or Novita


ABOUT THE ACCESSIBILITY SERVICE

ClosePaw uses Android's Accessibility Service to read screen content and perform actions on your behalf. The service is ONLY active during explicit task execution — it does not monitor your activity in the background, and you can stop any task at any time. This is the same API used by Voice Access, Switch Access, and other assistive Android apps.
